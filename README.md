# 救急 U 盘 构建与分发框架

[![License: MIT](https://img.shields.io/badge/License-MIT-yellow.svg)](LICENSE)

> **想直接用？** 点页面上方绿色的 **`Code`** 按钮 → **`Download ZIP`**，解压即得整套框架。
> 第三方工具不在压缩包里，解压后请按 [获取清单.md](获取清单.md) 自行下载。

## 它解决的是什么

系统进不去、硬盘出问题、装完系统没网、怀疑中毒——这些时候需要一张"什么都能干一点"的盘，而不是一堆零散工具的压缩包。

现成的"工具合集"通常有两个问题：体积失控、来源难辨；换一台机器又不知道该用哪个。而自己从零整理，往往会卡在目录怎么分、启动怎么配、改完怎么确认没被换过这些细节上。

## 这个仓库提供什么

**结构，而不是合集。**

| 提供 | 对应 |
|---|---|
| 引导方案 | Ventoy 承载多个镜像，一张盘同时装 PE、Linux 救援、Windows 安装盘 |
| 目录规范 | 00~09 十个按用途划分的编号目录，翻开就知道哪个工具在哪 |
| 处理路径 | [docs/救急流程卡.md](docs/救急流程卡.md)：六类常见故障的处置顺序与命令速查 |
| 获取指引 | [获取清单.md](获取清单.md)：每个软件的官方地址与放置位置 |
| 维护手段 | [scripts/初始化救急U盘.ps1](scripts/初始化救急U盘.ps1)：目录归位、缺失检查、生成 SHA256 台账 |
| 复刻方式 | [scripts/一键复制救急盘.bat](scripts/一键复制救急盘.bat)：整套复制到新盘，自动跳过个人文件夹 |
| 责任边界 | [DISCLAIMER.md](DISCLAIMER.md) 与 [LICENSE](LICENSE) |

## 边界

本仓库**不包含任何第三方二进制文件**（系统镜像、PE、驱动、商业软件）。

原因有两个：系统镜像动辄 8 GB，公开仓库放不下；更重要的是，多数第三方软件不允许再分发。所以这里只保留能公开的部分，具体工具请按 [获取清单.md](获取清单.md) 从官方渠道获取。

## 目录结构

```
U盘根目录\
├─ 00_说明\          使用说明、流程卡、机器配置单、哈希台账、缺失清单
├─ 01_PE\            启动镜像（WinPE / SystemRescue / 救援盘）
├─ 02_系统镜像\      原版 Windows ISO
├─ 03_驱动\          网卡 / 芯片组 / 存储驱动
├─ 04_运行库\        7-Zip、WinRAR、VC++、.NET 3.5 离线源
├─ 05_磁盘数据\      DiskGenius、TestDisk / PhotoRec
├─ 06_杀毒排查\      急救箱、专杀、Sysinternals、可启动杀毒
├─ 07_系统修复\      Dism++、引导修复
├─ 08_便携工具\      各种绿色小工具
├─ 09_硬件检测\      硬件检测工具包
├─ _个人\            个人文件（脚本永不触碰，分发时自动排除）
├─ autorun.inf\      同名文件夹，免疫 autorun 型病毒
├─ 初始化救急U盘.ps1  维护脚本：建目录、归位工具、生成文档与台账
└─ 一键复制救急盘.bat 分发脚本：把工具复制到另一张盘
```

## 快速开始

### 1. 准备 U 盘

建议 32 GB 以上（工具装满约 24 GB）。**先备份 U 盘内容**，下一步会格式化。

### 2. 装 Ventoy

到 <https://www.ventoy.net> 下载 Windows 版，安装时注意：

- 分区类型选 **MBR**
- 勾选 **安全启动支持**（否则在开了 Secure Boot 的机器上无法启动）

### 3. 初始化目录

把 `scripts/初始化救急U盘.ps1` 放到 U 盘根目录，然后：

```powershell
# 先预览，看清楚会动哪些文件
powershell -ExecutionPolicy Bypass -File .\初始化救急U盘.ps1 -Root E:\ -Organize -WhatIfOnly

# 确认无误后执行
powershell -ExecutionPolicy Bypass -File .\初始化救急U盘.ps1 -Root E:\ -Organize
```

### 4. 下载工具

按 [获取清单.md](获取清单.md) 里的官方地址，把 ISO 和工具放进对应目录。

### 5. 生成哈希台账

```powershell
powershell -ExecutionPolicy Bypass -File .\初始化救急U盘.ps1 -Root E:\ -HashAll
```

### 6. 实测

**没测过的救急盘等于没有。** 务必在一台真机上验证：

- 能进 Ventoy 菜单
- PE 能进桌面
- PE 里能看到全部硬盘（尤其是 NVMe）

## 两个脚本

### `初始化救急U盘.ps1`

| 参数 | 作用 |
|---|---|
| `-Root` | 目标盘根目录（必填） |
| `-Organize` | 把根目录里识别出的工具移动到对应目录 |
| `-HashAll` | 生成 `00_说明\哈希台账.csv`（自动排除 `_个人`） |
| `-WhatIfOnly` | 预览模式，不写入任何文件 |

### `一键复制救急盘.bat`

双击运行，三步交互：

1. 显示免责声明，输入 `Y` 同意
2. 输入目标盘符（如 `E`）
3. 确认后开始复制，完成后自动校验

复制时自动跳过：

- `_个人\`（个人文件夹）
- `System Volume Information`、`$RECYCLE.BIN`
- `autorun.inf`（同名文件夹，需要目标盘自行创建）

> 该 bat 为 **GBK 编码**，在中文 Windows 的命令提示符下显示正常。
> 若你的系统使用 UTF-8 代码页，提示文字可能显示为乱码，但复制逻辑不受影响
> （脚本中不包含任何中文路径字面量）。

## 已知限制

- 首次在某台电脑上启动 Ventoy，会提示 `Verification failed: (0x1A) Security Violation`，
  这是安全启动的正常流程，需要注册一次密钥。步骤见 [docs/救急流程卡.md](docs/救急流程卡.md)。
- 每台电脑只需注册一次；换机器要重做。
- 32 GB 的盘装完约剩 5 GB，建议不要往里塞其他东西。
