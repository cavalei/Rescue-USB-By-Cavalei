# 救急流程卡

> 打印一份放 U 盘里，或者直接看这个文件。

---

## 第 0 步：先判断，别急着动手

- **盘里的数据重要吗？**
  - 重要 → 立刻停止一切写入，先进 PE 做只读镜像
  - 不重要 → 可以直接修
- **是硬件问题还是软件问题？**
  - 听到异响 / 不认盘 / SMART 报红 → 按硬件故障处理

---

## 场景 A：开不了机 / 蓝屏 / 引导损坏

1. U 盘启动进 PE
2. 先确认能不能看到系统盘（看不到 → 见场景 D）
3. 能进 PE 但进不去系统 → 先备份重要文件，再修引导
4. 修引导优先级：**Dism++ 的「引导修复」 > `bcdboot` > `bootrec`**
5. 修不好再考虑「保留数据重装」

---

## 场景 B：误删 / 格式化 / 分区丢失

1. **立刻停止对该盘的一切写入**
2. DiskGenius 先「备份分区表」，再尝试恢复文件
3. 分区表乱了 → TestDisk 重建
4. 文件系统级恢复 → PhotoRec（按文件签名找回，不看分区表）
5. **目标文件一定恢复到另一块盘**

---

## 场景 C：硬盘有坏道 / 读取困难

1. 不要用 DiskGenius 直接扫故障盘反复读
2. Linux Live（SystemRescue）下用 `ddrescue` 做整盘镜像，跳过错误块
3. 在镜像文件上做恢复，原盘只读挂载
4. 实在救不回，考虑开盘（专业机构）

```bash
# SystemRescue 里的典型流程
ddrescue -d -r3 /dev/nvme0n1 /mnt/backup/disk.img /mnt/backup/disk.log
```

---

## 场景 D：PE 里看不到硬盘

**最常见原因：BIOS 里存储模式是 RAID / Intel RST（VMD）。**

解决顺序：

1. 换一个新内核的 PE 试试（FirPE 是 Win11 内核，支持更好）
2. 用 Dism++ 注入存储驱动（Intel RST / AMD RAID）
3. 临时把 BIOS 存储模式改成 AHCI（只是读数据的话，读完再改回）
4. 用 SystemRescue —— Linux 内核自带 NVMe/RAID 支持，经常能直接看到

另一个原因：**BitLocker**。分区能看到但打不开，需要 48 位恢复密钥。

---

## 场景 E：疑似中毒但系统还能进

1. 先断网
2. Autoruns 看自启项（重点：无签名、路径在 Temp/AppData 的）
3. Process Explorer / Process Hacker 看进程树和网络连接
4. 专杀工具跑一遍（火绒专杀 / 银狐专杀 / 360 急救箱）
5. 清不掉 → 进 PE 用可启动杀毒 ISO 离线扫

---

## 场景 F：中毒后系统已经进不去

用 Kaspersky Rescue Disk 启动，离线查杀。

同时用 PE 把重要文件拷出来 —— **注意：拷出来的文件可能带毒**，接到干净电脑上前先扫描。

## 常用命令速查

```cmd
:: 系统文件修复
sfc /scannow

:: 组件库修复
DISM /Online /Cleanup-Image /RestoreHealth

:: 引导重建（传统）
bootrec /fixmbr
bootrec /fixboot
bootrec /rebuildbcd

:: UEFI 引导修复
bcdboot C:\Windows /s S: /f UEFI

:: 磁盘检查
chkdsk C: /f /r

:: BitLocker
manage-bde -status
manage-bde -unlock D: -RecoveryPassword 恢复密钥
```

磁盘只读（进 PE 后、做数据恢复前）：

```cmd
diskpart
list disk
select disk N
attributes disk set readonly
```

看硬盘健康：

```powershell
Get-PhysicalDisk | Format-List FriendlyName, SerialNumber, HealthStatus
```

## U 盘启动不了？

### 症状 1：`Verification failed: (0x1A) Security Violation`

这台电脑的安全启动还不信任 Ventoy，**首次使用要注册一次密钥**：

1. 报错页按 **Enter**
2. `Shim UEFI key management` 的 7 秒倒计时内**按任意键**
3. 选 **`Enroll key from disk`**（不要选 `Continue boot`）
4. 选 **`VTOYEFI`** 分区（U 盘上那个 32 MB 的，没有盘符）
5. 选 **`ENROLL_THIS_KEY_IN_MOKMANAGER.cer`**
6. 依次 `Continue` → `Yes` → `Enroll` → `Reboot`
7. 再次启动，直接进 Ventoy 菜单

**每台电脑只需做一次；换机器要重做。**

备选：BIOS（F2）里把 Secure Boot 设成 `Disabled`。
但别人的机器上通常改不了，所以注册密钥是更通用的方案。

### 症状 2：启动菜单里找不到 U 盘

- 换 USB 口（直连，别用扩展坞）
- 长按电源强制关机再开（快速启动会影响 USB 枚举）
- 确认 BIOS 里 `Boot Mode` 是 UEFI、`Fast Boot` 关闭
- 机械革命等机型：启动菜单键常是 **F7** 而不是 F12

---

## 三条铁律

1. **数据恢复期间，绝对不要往故障盘写任何东西**
2. **不确定的时候先做整盘镜像，再在镜像上折腾**
3. **破解 / 绿化类工具只用于自己的设备**
